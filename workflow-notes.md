# GitHub Workflow Notes

## Repository
- Repository URL: https://github.com/tylerguest/swe325_525-github-ai-practice
- Default branch: `main`

## Issue
An issue defines the work to complete and the criteria for success.
- Issue URL: https://github.com/tylerguest/swe325_525-github-ai-practice/issues/1
- Purpose: Document GitHub workflow practice with AI assistance.

## Branch
A branch keeps changes separate from the default branch.
My feature branch is `feature/github-ai-workflow`.

## Commit
A commit records a set of changes with a message describing them.

## Pull Request
A pull request proposes merging changes from one branch into another
and provides a place to review them.

## Default Branch
The default branch is the repository's main branch.
In this repository, it is `main`, where completed work is merged.
